# withbugs.github.io

Published With Bugs website: https://withbugs.github.io/

The development source is maintained in [WithBugs.WebSite](https://github.com/withbugs/WithBugs.WebSite).
This release was generated from [the development commit](https://github.com/withbugs/WithBugs.WebSite/commit/46c85a2436641f695a10a0f95f43c6e1ba2bc18a).

The static files use Blazor WebAssembly / .NET 10 LTS and Three.js 0.186.1.
GitHub Pages publishes the root of the master branch after a push.
The .nojekyll file enables framework assets, and 404.html supports direct links to application routes.

Build the development project in Release mode and copy its published wwwroot contents here.
Replace the previous framework files as a set so old and new runtimes are not mixed.
